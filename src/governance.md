# Rules to agree before starting

Before any funded test, appoint an independent second human reviewer, establish who holds signing keys, and agree how each proposal destination/amount and off-chain description is verified. Membership, signers, threshold, token, dues and period settings are fixed at group creation.

Decide how to handle lost keys, unallocated direct transfers, archived state and off-chain disputes. v0 has no key rotation, membership change, dissolution refund, proposal expiry or period spending limits. Never describe this prototype as audited or safe for real funds. Deployment remains blocked.
