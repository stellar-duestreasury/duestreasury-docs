# DuesTreasury

A local v0 group treasury with fixed members, designated signers and threshold approvals. **TESTNET — no real money.** This custody prototype is not independently reviewed. Deployment remains blocked pending a second human reviewer; no deployed address or pilot is claimed.

Implementation: [contract entrypoints](https://github.com/stellar-duestreasury/duestreasury-contracts/blob/main/src/lib.rs), [app](https://github.com/stellar-duestreasury/duestreasury-app). These source changes may still be local until the maintainer publishes them.
